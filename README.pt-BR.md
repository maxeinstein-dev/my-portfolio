# Portfólio — Maxsuel Einstein

[English version](README.md)

Este repositório contém meu portfólio pessoal como desenvolvedor de software. O site apresenta minha trajetória profissional, foco técnico, experiências e projetos pessoais de forma direta, responsiva e acessível.

O conteúdo principal foi estruturado em inglês porque estou me preparando para buscar oportunidades internacionais. O site também oferece uma opção em português, com a preferência do visitante salva localmente para acessos futuros.

## Sobre O Site

- Portfólio estático desenvolvido com HTML, CSS e JavaScript.
- Conteúdo principal em inglês com alternância para português.
- Preferência de idioma persistida em `localStorage`.
- Interface responsiva para desktop e dispositivos móveis.
- Seções de apresentação, trajetória, experiência, projetos e contato.
- Estrutura leve, focada em carregamento rápido e manutenção objetiva.

## Foco Profissional

- Desenvolvimento Back-end com Java e Spring Boot.
- Experiência Full Stack em sistemas web personalizados.
- APIs REST, modelagem de domínio e arquitetura de software manutenível.
- Desenvolvimento Front-end com JavaScript e adoção progressiva de TypeScript.
- Qualidade de código, testes e manutenção de longo prazo.

## Projeto Em Destaque

**Stratega** é uma aplicação pessoal de planejamento financeiro criada para organizar carteiras, categorias e transações enquanto exploro modelagem de domínio e uma arquitetura preparada para evoluir.
