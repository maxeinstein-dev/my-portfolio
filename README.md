# Maxsuel Einstein Portfolio

[Versão em português](README.pt-BR.md)

This repository contains my personal portfolio as a software developer. The site presents my professional background, technical focus, work experience, and personal projects in a direct, responsive, and accessible format.

The content is intentionally written in English first because I am preparing for international opportunities. The website also includes a Portuguese language option, with the visitor's preference saved locally for future visits.

## About The Site

- Static portfolio built with HTML, CSS, and JavaScript.
- English-first content with a Portuguese translation toggle.
- Language preference persisted in `localStorage`.
- Responsive interface for desktop and mobile devices.
- Sections for introduction, background, experience, projects, and contact.
- Lightweight structure focused on fast loading and straightforward maintenance.

## Professional Focus

- Back-end development with Java and Spring Boot.
- Full Stack experience with custom web systems.
- REST APIs, domain modeling, and maintainable software architecture.
- Front-end development with JavaScript and progressive TypeScript adoption.
- Code quality, testing, and long-term maintainability.

## Featured Project

**Stratega** is a personal financial planning application designed to organize portfolios, categories, and transactions while exploring domain modeling and an architecture prepared to evolve.
